媒体目录

存储下载资源的父目录，默认取值自 Jellyfin 库路径。下载中/未完成的资源文件存储在媒体目录下的 .staging 目录中，下载完成后一次性移动到目标资源目录中。

资源站点

获取 magnet 和云盘链接的 BT 资源站点。系统内置两个，一行都没有时用内置默认。每个站点占一行，可以用行尾的按钮上下调整顺序——排序越靠前的搜索优先级越高。

关键词组合

留空时按条目类型自动取默认：剧集和综艺用剧集发布组那组署名，电影和纪录片用另一组——两类资源都能搜到候选，不用自己配。一旦填了，就按你写的搜，覆盖所有类型，按类型的默认不再生效；想让某一类回到默认，把这一栏清空即可。「单源」（只保留该发布组的候选）不是本页的开关，它也按条目类型走：只有剧集默认单源，电影、纪录片和综艺默认都不单源。内置默认的具体取值由插件后端维护，不在本页展示，免得两边各写一份。写法：一行一个关键词，多行按先后顺序依次搜索；同一行里的词是「全部命中」语义，所以不要把多个词写在同一行，也不要填电影名、导演这类只绑定单个资源的词。

热门

未配置 热门榜单的数据来自 TMDb：去 TMDb 账号设置（themoviedb.org/settings/api）申请一个 Key 后填在这里。它只写进本机插件配置，**不会下发到浏览器**——本页只回显「已配置 / 未配置」，所以这个输入框永远是空的。留空并保存 = 清除已存的 Key（要换 Key 就直接填新的）。
榜单的标题与简介按这个语言标签向 TMDb 请求，默认 zh-CN。留空并保存会回到 zh-CN。
「热门」页显示哪些榜单，默认四个全选。一个都不选并保存时按内置默认（四个全开）处理，而不是「一个都不显示」。
默认关闭；关闭时只记录关注，对媒体库零写入。打开后，关注一个榜单条目会在媒体库里放一个占位 mp4（位置就是它下载归档后的目录），让条目先在 Jellyfin 里可见；占位文件名带 zz placeholder 标签，不会与真正下载归档的文件撞名，也不会被重复关注覆盖。
