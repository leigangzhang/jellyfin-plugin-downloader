# Decision: 控制台配置页 —— 四组各三行、一个站点一个地址、端口行负责后端生命周期

[English](2026-10-13-console-config-page-redesign.md) | 中文

Status: implemented
Date: 2026-10-13
Class: feature

## 问题

插件的配置页向使用方索要插件自己可以推导或拼接的东西，又把屏幕上已经有的信息再回显一遍。第一轮点出三个症状：字体与风格和控台上其它插件页不一致、元素间距松散到整页看起来发空、以及三行本不该存在的回显 —— 解析出来的媒体目录（`当前解析到 …`）、只读的暂存目录、后端那行 `正在运行 · pid … · 插件管理`。

一屏里塞了七组东西：后端服务、端口、Python 解释器、媒体目录、暂存目录、每站四个字段的资源站行、以及关键词文本域。站点那四个字段把地址 —— 使用方唯一有意见的部分 —— 放在最不显眼的位置；每一组的行高各说各话；页面自造的 CSS 还引入了控制台不用的排版，`code` 标签和等宽字体的媒体目录回显都在其中。

页面同时提供 Python 解释器输入框和安装入口，而它们服务的那个前提 —— 机器上有一个 3.9+ 的 Python —— 写在使用方不会去看的地方。

## 决策

1. [configPage.html](../../../../Jellyfin.Plugin.JellyfinDownloader/Configuration/configPage.html) 是四组，顺序为 媒体目录 → 资源站点 → 关键词组合 → 服务端口，每组由「小节标题 / 它拥有的输入框或列表 / 一行说明」三行构成。七组那一屏没有了。
2. 一个站点就是一个地址。页面按使用方的写法显示和接收站点；保存时由插件把接口路径（`/api/search`、`/service/search`）拼进去再落盘，载入时把已知的默认路径折回裸站点。带 `{q}` 的地址是云盘搜索页，单独保留自己的入口。插件认不出来的主机在保存时被拒，而不是按猜测的类型存下去。
3. 资源站与关键词共用同一套列表交互：一条一行，行尾是上移 / 下移 / 删除，`+` 只在最后一行，每一行都能删（包括刚用 `+` 加出来的空行），列表被删空后自动补一个空行。
4. 媒体目录是使用方唯一要填的路径；留空表示由插件从 Jellyfin 库根解析，并把解析结果显示成 placeholder。暂存固定为该库根下的 `.staging`，只读回显。
5. 页面的风格就是控制台自己的：组标题用 `.sectionTitle`、输入框用 `.emby-input`、说明用 `.fieldDescription`、动作用 `button-alt`、行控用主题自带的图标按钮。页面自带的 CSS 只留主题没有对应类的排布。凡是尺寸必须与主题一致的地方，复用的是主题的元素与类，而不是抄来的数字 —— 端口标签是 `h2.sectionTitle`，不是 `1.5em`。
6. 端口行显示 `host:port`、状态徽标（运行中 / 已停止 / 启动中）、刷新状态与重启后端。它没有端口输入框，也不渲染 pid。端口在启动时定下 —— 配置的 8123，或者往后第一个空闲端口。保存会重启后端，因为新配置就是这样抵达它的。
7. 后端归属被限定两次：插件只停自己 pidfile 里记着的那个进程，绝不停「谁在监听这个端口」；它靠 JSON 响应里的 `service` 标识认出自己的后端，而不是靠「这个端口上有人应答」。
8. 默认值住在插件里，不在页面的标记里：两个内置站点以裸站点存储（`https://m.diao.im`、`https://torrents-csv.com`），三条关键词各一个词（`高清剧集网`、`DDHDTV`、`BBHDTV`）。配置为空时渲染它们，而不是空输入框；C# 与 Python 两份副本被断言逐字相同。Python 解释器不是配置项：它的输入框与安装入口都已删除，那个前提连同各平台命令写在 [README.md](../../../../README.md) 的「快速开始」第 0 步，文案由 [PythonInstaller.cs](../../../../Jellyfin.Plugin.JellyfinDownloader/PythonInstaller.cs) 拥有。

资源站与关键词为什么会变成插件配置，是另一个决定，记录在 [ranking-sources](../architecture/2026-10-13-ranking-sources.zh.md) 与 [ranking-flow-simplification](../architecture/2026-10-13-ranking-flow-simplification.zh.md)。

## 曾考虑的替代方案

**在七组那一屏上打磨，而不是换掉它。** 那是页面既有的形状，改动面会小得多。它落选是因为问题在布局而不在样式：站点行的四个字段把地址埋了、每组各设自己的节奏，而再多的样式调整也没法让一个四字段行读起来像一个站点。这次是换掉了布局（`5f97c8c`）。

**要求页面填完整接口地址。** 那样使用方输入的就是落盘的内容，不需要相信任何拼接。它落选是因为接口路径是插件的知识、不是使用方的：内置站点是以裸主机被认知的，而填错的路径会得到一个「看起来配好了、永远不应答」的站点。现在保存时拼接、载入时把已知路径折回（`5574fd8`）。

**停掉占用端口的一切进程。** 第一版实现在配置端口上跑 `lsof` 并杀掉监听者。它落选是因为它从不校验归属：8123 上无关的服务会被杀掉，而本该发生的「自增」只在杀不掉时才生效。已换成 pidfile 限定的停止加 `ResolvePort`（`c59cc5d`）。

**用「端口上有应答」判断「我们的后端在跑」。** 它两次落选：8123 上一个返回 404 或 2xx JSON 的外部 HTTP 服务会让插件不去启动自己的后端；而第一版修法（把 500 以下都当成自己）仍然分不清两者。现在后端在每个 JSON 响应上盖 `service` 标识，插件解析它（`f801a37`）。

**保留一个使用方能编辑的端口。** 页面原本接收端口值。它落选是因为端口的身份就是「后端实际监听在哪」，而这是配置端口被占时在启动时定下的 —— 一个可编辑的字段会与它旁边的徽标互相矛盾。这一行改成了只读展示（`5f97c8c`、`0432907`）。

**给状态文字上色，而不是填充徽标背景。** 落选靠的是测量而不是口味：绿色 `#2e9e4f` 对白底 3.43:1、琥珀 `#d79b00` 2.45:1，达不到 AA；也没有任何一种颜色能同时在白底与近黑底上过 4.5:1。实心胶囊自带 4.72–6.05:1（`f413ecf`）。

**保留一条列出全部三个词的关键词行。** 那是第一轮的模板值，也确实先落地了。它落选靠的是测量：这个索引对一条查询里的词是 AND 语义，所以 `漫长的季节 高清剧集网 DDHDTV BBHDTV` 对每部片都返回 0 条，而把 `BTHDTV` 换进去的那条返回 10 条。使用方选择了一行一个词共三行，那份测量留在 `backend/source_config.py` 里当理由（`12eec0b`、`f7068cb`）。

**保留 Python 解释器输入框与安装入口。** 落选是因为页面的职责是「插件能推导或自己拥有的东西」：解释器是机器的属性，而这个字段唯一的作用是推翻自动探测。步骤移到了 README，文案由 `PythonInstaller.cs` 拥有，被删掉的那两个标签变成了一条禁用语，好让任何文档都不能再承诺它们（`5f97c8c`、`fc46e2d`）。

## 后果

- 页面现在是控制台自己的页面：排版由三个主题类承载，页面自带的 CSS 只保留列表与端口的排布，组标题、说明与输入框和控台其它插件页对齐。
- 落盘的站点值是完整接口地址，而页面说的是站点名。正因如此内置默认才读得懂，也意味着索引接口路径的变更变成插件侧的改动，而不是使用方的。
- 后端挂掉可以从页面上救回来：徽标显示「已停止」，点「重启后端」就拉回。验证方式是真杀掉进程再读那一行（`1978169`）。
- 端口的真相是一个值。代理读 `BackendManager.BaseUrl`，于是自增后的端口能到达面板；在这之前自动自增的端口会让整个面板 502，等于把自增这个功能从头到尾悄悄作废（`f8e22d2`）。
- 保存会重启后端。它正在跑的任务会被打断；这是「配置以环境变量抵达」的代价。
- 三条关键词行意味着每部片要对搜索预算发三次查询，而 `BBHDTV` 在被测量的索引上返回 0 条 —— 这是使用方明确接受的代价，附带说明就写在默认值旁边。
- 控制台现在依赖主题的类与变量。一个改掉 `.sectionTitle` 或不再提供 `paper-icon-button-light` 的主题，会在不碰这个页面的情况下改变它的外观；这池主题名就是本决定选择换掉的耦合：代价是不再自持一份样式表。
- 这次工作在自己最初的版本里发现并修掉三个缺陷，都配了守卫：配置接口 500，因为同一个匿名对象里同时有 `btSites` 与 `BtSites`（`System.Text.Json` 按大小写不敏感比较，编译器和单测都不会发现）；含空格的媒体根被 shell 切断，后端悄悄收到 `/Volumes/XIAOMI` 而不是真实路径；后端子进程继承了 Jellyfin 的整份环境，75 个变量里含明文凭据，现在清空并白名单到 22 个、没有一个是凭据形状（`550d3a4`、`c284520`、`203a081`）。
- 存量配置继续可用：双入口站点不再被误判成云盘页，未知主机且未声明类型会被拒绝而不是兜到内置类型，自建站点的类型现在能经一次保存原样往返，而不是被改写成别的（`c59cc5d`、`f801a37`、`db85433`）。

## 验证

- [C1] `tests` — [test_backend_retired_config_page.py](../../../../tests/backend_retired/test_backend_retired_config_page.py) 承载页面源码侧的守卫（53 条断言）：被删的行保持删除；端口行渲染三种状态且永不渲染 `status.pid`；媒体目录输入框的宽度由共享的 `--jdl-actions-width` 变量算出，因而不可能与两个列表漂移；徽标配色在测试内部按 WCAG AA 计算；关键词默认里不含空格；C# 与 Python 两份默认逐字相等。
- [C2] `source` — 那些守卫背后的行为是在运行中的实例上验证并记进提交的：保存写入完整接口地址并重启后端（`550d3a4`）；杀掉后端后那一行显示「已停止」、点重启按钮拉回（`1978169`）；自增端口能经代理到达面板（`f8e22d2`）；含空格的媒体根完整送达（`c284520`）。
- [C3] `source` — 后端一侧钉在同一套测试里：每个 JSON 响应上的 `service` 标识、启动时写、退出时删的 pidfile、作为端口唯一通道的 `JMD_PORT`，以及 [BackendManager.cs](../../../../Jellyfin.Plugin.JellyfinDownloader/BackendManager.cs) 里的 `Environment.Clear()` 与白名单。
- [C4] `tests` — 两条静态扫描让 C# 一侧保持诚实：扫描插件源码里所有匿名对象，禁止只差大小写的键；两份默认值彼此比对。
- [C5] `docs` — [README.md](../../../../README.md) 按页面现状描述它（四组、站点地址模型、三条关键词行、解释器见「快速开始」第 0 步），并且 `banned-spellings` 检查会拒掉被删的安装入口标签，于是文档无法再承诺一个页面没有的控件。
