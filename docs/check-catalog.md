# Check catalog (generated page)

> Generated by `python3 tools/gen-docs.py`; never edit it by hand. Regenerate with `python3 tools/gen-docs.py`; freshness: `python3 tools/gen-docs.py --check`. The fact source is [tools/workflow.json](../tools/workflow.json).

This page lists the changed surfaces and the gates this repository declares right now: a surface answers "which evidence do I run after changing this path", and a gate answers "which convention turns red when it is violated". Why each one exists, and what it gave up, lives in the decision records under [.agents/notes/](../.agents/notes/implemented/TEMPLATE.md); the decision logic is not restated here, only executed in [tools/check-invariants.py](../tools/check-invariants.py) and [tools/pair-docs.py](../tools/pair-docs.py).
